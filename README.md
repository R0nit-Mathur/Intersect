## Technical Architecture

Built upon a high-performance Webflow & Next.js 15 mirror preserving 100% of the original luxury editorial design and interactive engineering:
- **3D WebGL Background**: Three.js interactive canvas shaders (`hero_canvas_item`, `footer_canvas_item`, `seasonal-canvas`).
- **GSAP Motion Suite**: SplitText character reveals, ScrollTrigger scrubbed pinning, CustomEase curves, and Flip transitions.
- **Smooth Scrolling**: Lenis smooth scroll engine active across all 12,000+ vertical pixels.
- **100% Self-Hosted Assets**: All fonts, audio effects, videos, and scripts running locally with zero external tracking dependencies.
